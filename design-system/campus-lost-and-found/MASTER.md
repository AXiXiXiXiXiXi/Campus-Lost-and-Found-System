# 校园失物招领 · 界面设计规范

适用于 Django 渲染的校园失物招领业务页面。学生和教职工主要浏览物品、发布信息和跟进认领。管理员主要管理公告、审核认领和查看账户。采用 UI/UX Pro Max 的 Accessible & Ethical 方向，包括易读文字、低动效和清晰的键盘焦点。

## 视觉规则

- 使用浅灰绿底、白色卡片和深绿操作色。正文为 `#192b24`，辅助文字为 `#495c53`，主按钮为 `#1b5643`。状态标签同时显示文字。
- 使用本地中文无衬线字体栈。正文 16，辅助文字 14，时间与标签 13。卡片标题 18，分区标题 20，页面标题按视口缩放为 28–36。字号在样式中使用相对单位。
- 间距以 4、8、12、16、20、24、32 CSS 像素为基础。常规卡片内边距为 16–24，表单字段间距为 16，列表卡片间距为 12。
- 主操作用实底按钮。次操作用描边按钮或文字链接。主要按钮及表单输入区高度为 44 CSS 像素。悬停、按下、焦点及禁用状态各有清晰反馈，减少动态效果时保留静态反馈。

## 页面布局

| 页面 | 布局 |
| --- | --- |
| 首页 | 校园横幅、当前角色的常用操作、快速入口、近期公告和个人信息 |
| 失物、招领与认领 | 页首说明及主要操作、带标签的筛选区、结果数量与卡片列表。窄屏列表切换为单列 |
| 详情和审核 | 主要内容优先，关联物品、发布信息与操作集中在侧栏，窄屏顺序排列 |
| 公告 | 单列，以标题引导阅读，置顶和系统标签右对齐，长标题与标签可换行 |
| 登录与注册 | 无图居中表单，注册桌面端双列，手机端单列。学校搜索联动所属学校字段 |
| 账户管理与说明 | 桌面语义表格在手机端按用户分组。说明页面保留清楚的分节与目录 |

## 可访问性检查

- 常规文字和语义颜色配对的目标是至少 4.5:1。控件边界及焦点环的目标是至少 3:1。
- 键盘用户可以跳到正文，识别当前导航位置，进入和退出账户菜单，打开学校搜索，用方向键浏览并选中学校。
- 服务端验证失败时，表单顶部显示可定位的错误摘要。字段保留具体错误和关联属性。账号表单提供密码管理器可识别的自动填充属性。
- 以 320 和 390 CSS 像素窄屏及桌面为基准检查排版。照片保留替代文字，缺图占位和实际缩略图使用相同尺寸。

样式来源为 `static/lostfound/campus.css` 和 `static/lostfound/pages.css`。可访问性参考 [W3C WCAG 2.2 快速参考](https://www.w3.org/WAI/WCAG22/quickref/) 与 [组合框交互模式](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)。
